# Tesol — The Event Solutions

A polished three-page website for an event-planning studio, built with React, Vite, Tailwind CSS and Framer Motion.

## Pages

- `/` — Home, portfolio, process and enquiry form
- `/services` — Service details, approach and FAQs
- `/privacy` — Full privacy policy

## Run locally

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`. When deploying a single-page app, configure the host to rewrite unmatched routes to `index.html` so direct visits to `/services` and `/privacy` work correctly.

## Customise before launch

Replace the placeholder brand contact details, Instagram URL and enquiry form handler with the business's real information. The privacy policy is a strong general template, but it should be reviewed against the business's actual data practices before publication.
